PSX 3D Studio — basic controls

Open OBJ / project loads a mesh or a saved session. Load the PNG texture separately for OBJ files. Everything runs locally, without a server.

Choose Vertices or Faces, click to select and use Shift to add to the selection. Drag a rectangle to box select; vertex mode also includes hidden vertices. Move drags the selection along the view plane or the chosen axis.

Build a model by adding, moving and scaling shapes. For Create face, select three or four vertices in boundary order using Shift. Extrude face works on a single face along its normal. Merge vertices welds selected points; Clean up removes unused vertices and UVs.

UVs: select a face. Drag its points on the texture or edit U/V in the numeric fields. Mapping assigns the entire texture to each face; preserve existing UVs when working with a character atlas.

PS1: the current loader supports up to 256 quads, 2048 vertices and 2048 UVs. OBJ export preserves axes and dimensions: the Y checkbox changes only the view. Animation poses are separate OBJ files; this editor has no rig or timeline.

Shortcuts: V select, G move, A select all, Esc deselect, Delete remove, F frame all, Ctrl+Z undo, Ctrl+Shift+Z redo, Ctrl+S save project.

Save project stores the mesh and PNG in a JSON file. Export OBJ downloads the geometry; for other programs choose Standard OBJ and export the MTL too if you use a texture.
